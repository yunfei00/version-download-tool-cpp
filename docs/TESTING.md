# TESTING

## 1. 构建验证
1. 安装 Qt6（Widgets + Network）和 CMake 3.21+。
2. 执行：
   ```bash
   cmake -B build -S .
   cmake --build build --config Release
   ```
3. 期望：可生成 `VersionDownloadTool`（Linux/macOS）或 `VersionDownloadTool.exe`（Windows）。

## 2. 扫描功能验收
1. 启动程序，输入 HTTP/HTTPS 目录 URL。
2. 点击“扫描”。
3. 检查：
   - 可递归发现子目录文件。
   - `../`、排序链接（如 `?C=N;O=D`）、空链接、外部域名链接不会作为文件。
   - 表格“文件名/相对路径”是相对路径（包含子目录层级）。

建议测试地址：
- 一个标准目录索引（含子目录）
- 一个含查询参数排序链接的目录索引页面

## 3. 下载功能验收
1. 先完成扫描。
2. 设置本地保存目录。
3. 点击“开始下载”。
4. 检查：
   - 文件能下载到本地。
   - 保持远程目录结构。
   - 已存在且大小一致时显示“已存在”并跳过。
   - 进度列实时更新。
   - 当前下载行会自动滚动到可见区域。
5. 下载中点击“停止下载”，检查日志出现停止信息且后续任务不再继续。

## 4. 异常处理验收
- 远程地址为空点击扫描：不崩溃并输出参数错误日志。
- 本地目录为空点击下载：不崩溃并输出参数错误日志。
- 网络错误：日志包含具体失败原因。
- 下载失败：对应行状态显示“失败”。
- 本地目录不可创建：日志提示“无法创建目录”。

## 5. 配置保存验收
1. 输入远程地址和本地目录后关闭程序。
2. 重新打开程序。
3. 检查输入框恢复上次内容（QSettings）。

## 6. GitHub Actions 打包验收
1. 推送 `v*` tag 触发 workflow。
2. 下载发布 zip，检查至少包含：
   - `VersionDownloadTool.exe`
   - `Qt6Core.dll`
   - `Qt6Gui.dll`
   - `Qt6Widgets.dll`
   - `platforms/qwindows.dll`
